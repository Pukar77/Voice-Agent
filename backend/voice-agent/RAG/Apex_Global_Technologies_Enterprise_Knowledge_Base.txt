21. Technical Knowledge Base FAQs: ERP & Cloud
Q1: How does Apex ERP handle multi-company, multi-currency ledger consolidation?
Answer: Apex ERP features an automated multi-currency translation engine that pulls live foreign exchange rates daily from
central bank APIs. Inter-company transactions are automatically matched and eliminated during month-end financial
consolidation runs.
Q2: Can we run Apex ERP on our own private Kubernetes cluster?
Answer: Yes. Apex Enterprise licenses include access to official Helm charts and private Docker registries, allowing full
deployment on Red Hat OpenShift, EKS, GKE, or bare-metal Kubernetes nodes.
Q3: What database engines are supported for local on-premises installations?
Answer: On-premises deployments strictly require PostgreSQL 15+ or distributed YugabyteDB clusters. Proprietary engines
like Oracle or MS SQL are supported via data sync connectors but not as primary transactional datastores.

22. Technical Knowledge Base FAQs: CyberShield Security
Q4: How does CyberShield perform endpoint detection without slowing down workstations?
Answer: The CyberShield sensor runs as an isolated lightweight system daemon utilizing eBPF on Linux and kernel mini-
filters on Windows. Sensor CPU utilization is capped at < 1.5% under peak traffic loads.
Q5: Is data sent to the AI Threat Hunter encrypted?
Answer: Yes. All telemetry logs are encrypted on the agent side using AES-256 before transit via TLS 1.3 channels to
isolated regional processing pods.
Q6: Does CyberShield support legacy operating systems like Windows Server 2012?
Answer: CyberShield provides legacy extended support agents for Windows Server 2012 R2 and RHEL 7, though zero-trust
network microsegmentation features are recommended for outdated platforms.

23. Technical Knowledge Base FAQs: VoiceAI Systems
Q7: What is the typical deployment timeline for a VoiceAI inbound call system?
Answer: Standard deployments using pre-built CRM integration workflows take between 5 to 10 business days. Custom LLM
prompt engineering and proprietary telephony integration usually span 3 to 4 weeks.
Q8: How does the VoiceAI agent handle caller interruptions or barge-in?
Answer: The VoiceAI engine incorporates full-duplex audio stream analysis. If a customer speaks while the agent is
generating output, the agent halts speech synthesis within 120ms and listens for the new user input context.
Q9: Can VoiceAI transfer calls directly to human agent phone lines?
Answer: Yes. VoiceAI executes cold or warm SIP transfers directly to standard PBX call queues, forwarding full call
transcription metadata to the agent's CRM screen before connection.
